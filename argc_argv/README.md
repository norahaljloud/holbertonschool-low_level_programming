# 0x0A. argc, argv

## Task 0: It ain't what they call you, it's what you answer to

Prints the name of the program using argv[0].
The program prints its current executable name, including its path.

## Task 1: Silence is argument carried out by other means
Prints the number of command-line arguments, excluding the program name.

## Task 2: args
Prints all command-line arguments, including argv[0].

## Task 3: Neither irony nor sarcasm is argument

Multiplies two command-line integers using atoi().
Prints Error and returns 1 if the argument count is incorrect.

## Task 4: To infinity and beyond

Adds positive command-line integers.
Prints 0 when no numbers are provided.
Prints Error and returns 1 if any argument contains non-digit characters.
