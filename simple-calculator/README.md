# Simple Calculator

## Compilation
Compile using:
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Run Instructions
Run the program using:
./calculator

## Supported Operations
- Addition
- Subtraction
- Multiplication
- Division
- Quit using option 0

## Numeric Behavior
The program uses integers for menu selection. Decimal calculations are not implemented yet.

## Known Limitations
- Non-numeric input validation is not supported.
- Arithmetic operations will be implemented in subsequent tasks.
